4.1. Общая модель оценки

Параметр Описание
Уровни оценки Показатель → Группа показателей → Интегральный индекс эффективности
Периодичность Оперативный мониторинг — ежемесячно; сводная оценка — ежеквартально; годовой отчёт — ежегодно
Ответственные Тренеры и руководители подразделений — сбор данных; методист/аналитик — расчёт и свод; директор — утверждение и решения
Источники данных Журналы посещаемости, отчёты тренеров, протоколы соревнований, данные ГТО, бухгалтерская отчётность, опросы, публичная отчётность
Метод расчёта индекса Взвешенная сумма оценок групп (веса: результативность 25%, охват 25%, удовлетворённость 20%, ресурсы 20%, оргэффект 10%)

4.2. Методика расчёта показателя (общая схема)

Для каждого показателя используется единый шаблон методики (полный шаблон — в папке templates/):

  1. Формула — математическое выражение с пояснением переменных и источников.
  2. Шкала — качественная интерпретация значений (критический / низкий / средний / высокий уровень).
  3. Целевые значения — базовые и плановые значения на горизонте планирования.
  4. Источники данных — конкретные документы и системы.
  5. Порядок использования — как значение влияет на управленческие решения.

4.3. Пример методики: Коэффициент сохранности контингента (KP-02-02)

Элемент Содержание
Формула Кск = (Чпродолживших за год) / (Чзанимавшихся на начало года) × 100%
Шкала ≥ 90% — высокий; 75–89% — средний; 60–74% — низкий; < 60% — критический
Целевые значения Год 1 — 80%; Год 2 — 85%; Год 3 — 90%
Источники данных Журналы посещаемости, АИС спортивной подготовки, приказы о зачислении/отчислении
Управленческое решение Выявление программ с оттоком; корректировка расписания; опросы причин ухода; повышение квалификации тренеров

4.4. Формы представления результатов

1

Отчёт

Ежеквартальный и годовой отчёт с таблицами, динамикой показателей, анализом отклонений и рекомендациями (шаблон в templates/otchet-ob-otsenke.md).

2

Дашборд

Аналитическая панель (прототип на главной странице сайта) с KPI, прогресс-барами, индексами и статусами.

3

Реестр показателей

Структурированный перечень показателей с кодами, группами, ответственными и целевыми значениями.

4.5. Регламент использования результатов оценки

Этап Действие Ответственный
Сбор данных Внесение первичных данных по показателям Тренеры, руководители подразделений
Расчёт Вычисление значений показателей, групповых оценок и индекса Методист / аналитик
Анализ Сопоставление с целями, выявление отклонений, подготовка рекомендаций Методист / аналитик
Утверждение Рассмотрение результатов, утверждение решений Директор
Коммуникация Доведение результатов до персонала, учредителя, публичная отчётность Директор, отдел бухгалтерии
Контроль Мониторинг исполнения решений, корректировка целевых значений Директор, Наблюдательный совет
Продуктовые элементы блока: система показателей, методики расчёта, шаблон отчёта, прототип аналитической панели, регламент использования — все доступны в репозитории проекта.
