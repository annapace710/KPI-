2. Определение состава показателей и критериев оценки

Система показателей построена на базе методологии KPI и сбалансированной системы показателей (BSC), адаптированных к специфике физкультурно-спортивных организаций. Каждый показатель сопровождается обоснованием выбора и описанием связи с целями организации.

2.1. Группы показателей

  1. Результативность — спортивные достижения, выполнение разрядных норм.
  2. Охват и устойчивость контингента — число занимающихся, сохранность контингента.
  3. Удовлетворённость потребителей — опросы родителей, занимающихся, участников мероприятий.
  4. Эффективность использования ресурсов — кадровые, инфраструктурные, финансовые ресурсы.
  5. Организационный эффект — кадровая стабильность, вовлечённость персонала.

2.2. Система показателей (структурированный перечень)

Код Группа Показатель Ед. изм. Источник данных Связь с управленческим решением
KP-01-01 Результативность Количество призовых мест на соревнованиях (по уровням) ед. Отчёты тренеров, протоколы соревнований Оценка качества спортивной подготовки, мотивация тренеров
KP-01-02 Результативность Число спортсменов, выполнивших разрядные нормы чел. Приказы о присвоении разрядов Планирование спортивной подготовки, отчёт учредителю
KP-01-03 Результативность Доля занимающихся, сдавших нормативы ГТО на знак отличия % Данные Центра тестирования ГТО Оценка выполнения муниципального задания по ГТО
KP-02-01 Охват и устойчивость контингента Численность занимающихся на систематической основе чел. Журналы посещаемости, АИС Оценка охвата, планирование нагрузки
KP-02-02 Охват и устойчивость контингента Коэффициент сохранности контингента (доля продолживших занятия) % Журналы посещаемости Выявление программ с высоким оттоком

KP-03-01 Удовлетворённость потребителей Индекс удовлетворённости (по опросам) балл Опросы родителей и занимающихся Корректировка программ, работы с персоналом
KP-03-02 Удовлетворённость потребителей Доля положительных обращений/жалоб в общем потоке % Журнал обращений Оценка качества услуг, работа с жалобами
KP-04-01 Эффективность использования ресурсов Доля tренеров с профильным образованием % Кадровые документы Развитие кадрового потенциала
KP-04-02 Эффективность использования ресурсов Загрузка инфраструктуры (часы использования залов) % Расписание, аренда Оптимизация использования площадей
KP-04-03 Эффективность использования ресурсов Доля внебюджетных доходов в общем объёме % Бухгалтерская отчётность Оценка финансовой устойчивости, поиск грантов
KP-05-01 Организационный эффект Коэффициент текучести кадров % Кадровые документы Оценка стабильности коллектива
KP-05-02 Организационный эффект Индекс вовлечённости персонала балл Опросы сотрудников Мотивация, премирование, климат

2.3. Пример обоснования показателя

Пример: Коэффициент сохранности контингента (KP-02-02).
Связь с целями: отражает устойчивость контингента — одну из ключевых целей учреждения (привлечение и удержание жителей к регулярным занятиям).
Доступность данных: журналы посещаемости, АИС «Спорт» — данные доступны на уровне каждой группы.
Практическая применимость: рассчитывается силами методиста/тренера без внешних специалистов.
Связь с решениями: при снижении показателя выявляются программы с оттоком, принимаются меры (корректировка расписания, повышение квалификации тренеров, опросы причин оттока).

2.4. Критерии оценки показателей

  • Релевантность — показатель отражает значимый аспект деятельности организации.
  • Измеримость — наличие объективных числовых значений.
  • Доступность данных — данные собираются из существующих или легко внедряемых источников.
  • Управляемость — на показатель можно влиять управленческими решениями.
  • Сопоставимость — возможность сравнения с целевыми значениями и прошлыми периодами.
