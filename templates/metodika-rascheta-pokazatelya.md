> **Подсказка для показателей группы «Удовлетворённость потребителей»:** в качестве внешнего подтверждённого источника рекомендуется использовать результаты **независимой оценки качества условий оказания услуг (НОК)** из ГИС ГМУ (bus.gov.ru, карточка учреждения). Для KP-03-01 показатель принимается равным итоговому баллу НОК; для KP-03-03 — подкритериям «удовлетворённость информацией на сайте / на стендах». Собственные опросы могут дополнять, но не заменять НОК.

> **Подсказка для показателей группы «Эффективность использования ресурсов»:** KP-04-01 (укомплектованность основного персонала) рассчитывается по данным ГИС ГМУ (штатная/фактическая численность) и кадровым документам; KP-04-03 (финансовая автономия) соответствует блоку «А» интегральной оценки эффективности учреждения в ГИС ГМУ.
