# Методика расчёта показателей оценки эффективности

**Организация:** Берёзовское муниципальное автономное учреждение «Центр развития спорта» (БМАУ ЦРС)
**Блок 4 проекта:** Разработка модели оценки и формы представления результатов
**Версия:** 1.1 (актуализировано по итогам первичной апробации модели, Блок 5)

---

## 1. Общие положения

Настоящий документ содержит полную методику расчёта всех показателей оценки эффективности деятельности физкультурно-спортивной организации. Методика построена на базе подходов KPI и сбалансированной системы показателей (BSC), адаптированных к специфике ФСО.

Для каждого показателя приводятся:

- код и наименование;
- группа показателей;
- единица измерения;
- периодичность расчёта;
- ответственные за сбор данных и расчёт;
- обоснование выбора (связь с целями организации);
- формула расчёта и пояснение переменных;
- шкала оценки (качественная интерпретация);
- целевые значения;
- источники данных;
- порядок использования в управленческих решениях.

**Веса групп показателей в интегральном индексе:**

| Группа | Вес |
|---|---|
| Результативность | 25% |
| Охват и устойчивость контингента | 25% |
| Удовлетворённость потребителей | 20% |
| Эффективность использования ресурсов | 20% |
| Организационный эффект | 10% |
| **Итого** | **100%** |

## 2. Группа «Результативность»

### 2.1. KP-01-01. Количество призовых мест на соревнованиях (по уровням)

| Параметр | Значение |
|---|---|
| **Группа** | Результативность |
| **Единица измерения** | ед. |
| **Периодичность** | ежеквартально, ежегодно |
| **Ответственный за сбор** | Руководитель образовательного подразделения, тренеры |
| **Ответственный за расчёт** | Методист / аналитик |

**Обоснование:** отражает качество спортивной подготовки и результативность участия в соревнованиях; напрямую связан с целью «Подготовка спортивного резерва, спортивных команд и спортсменов высокой квалификации».

**Формула:**

```
П = Σ (N_приз_муниц + N_приз_рег + N_приз_фед + N_приз_всеросс)
```

Где:
- `N_приз_муниц` — число призовых мест на муниципальных соревнованиях;
- `N_приз_рег` — на региональных соревнованиях;
- `N_приз_фед` — на федеральных (окружных/межрегиональных);
- `N_приз_всеросс` — на всероссийских соревнованиях.

Для оценки по уровням возможно взвешивание: муниципальный уровень — коэффициент 1, региональный — 2, федеральный — 3, всероссийский — 4.

**Шкала оценки:**

| Уровень | Значение (взвешенное) | Интерпретация |
|---|---|---|
| Критический | < 100 | Редкое участие, слабая соревновательная практика |
| Низкий | 100–149 | Участие есть, призовые места единичны |
| Средний | 150–199 | Стабильное участие и призовые места |
| Высокий | ≥ 200 | Системное участие с высокими результатами |

**Целевые значения:** Год 1 — 150; Год 2 — 170; Год 3 — 200.

**Источники данных:** протоколы соревнований, отчёты тренеров, приказы о направлении на соревнования, публичная отчётность.

**Управленческие решения:** оценка эффективности тренеров, распределение ресурсов на выезды, корректировка календарного плана.

### 2.2. KP-01-02. Число спортсменов, выполнивших разрядные нормы

| Параметр | Значение |
|---|---|
| **Группа** | Результативность |
| **Единица измерения** | чел. |
| **Периодичность** | ежегодно |
| **Ответственный за сбор** | Руководитель образовательного подразделения |
| **Ответственный за расчёт** | Методист / аналитик |

**Обоснование:** отражает системность спортивной подготовки и прогресс обучающихся; связан с целью подготовки спортивного резерва.

**Формула:**

```
Р = N_разряд + N_КМС + N_МС
```

Где:
- `N_разряд` — число спортсменов, выполнивших массовые разряды (III, II, I);
- `N_КМС` — число спортсменов, выполнивших КМС;
- `N_МС` — число спортсменов, выполнивших МС (и выше).

**Шкала оценки (для организации масштаба БМАУ ЦРС):**

| Уровень | Значение | Интерпретация |
|---|---|---|
| Критический | < 20 | Единичные разряды |
| Низкий | 20–39 | Разряды в отдельных видах |
| Средний | 40–59 | Системная работа по разрядам |
| Высокий | ≥ 60 | Высокая результативность подготовки |

**Целевые значения:** Год 1 — 45; Год 2 — 55; Год 3 — 65.

**Источники данных:** приказы о присвоении разрядов, протоколы соревнований, классификационные зачётки.

**Управленческие решения:** оценка программ спортивной подготовки, мотивация тренеров, планирование зачисления в группы.

### 2.3. KP-01-03. Доля занимающихся, сдавших нормативы ГТО на знак отличия

| Параметр | Значение |
|---|---|
| **Группа** | Результативность |
| **Единица измерения** | % |
| **Периодичность** | ежегодно |
| **Ответственный за сбор** | Центр тестирования ГТО |
| **Ответственный за расчёт** | Методист / аналитик |

**Обоснование:** отражает выполнение задач по внедрению ВФСК «ГТО» — одной из целей учреждения.

**Формула:**

```
Д_ГТО = (N_знак / N_протестировано) × 100%
```

Где:
- `N_знак` — число лиц, выполнивших нормативы на золотой/серебряный/бронзовый знак;
- `N_протестировано` — общее число протестированных лиц.

**Шкала оценки:**

| Уровень | Значение | Интерпретация |
|---|---|---|
| Критический | < 30% | Низкая результативность тестирования |
| Низкий | 30–49% | Средняя результативность |
| Средний | 50–69% | Хорошая результативность |
| Высокий | ≥ 70% | Высокая результативность |

**Целевые значения:** Год 1 — 50%; Год 2 — 60%; Год 3 — 70%.

**Источники данных:** протоколы тестирования, данные Центра тестирования ГТО, статистика комплекса ГТО.

**Управленческие решения:** оценка качества подготовки к ГТО, совершенствование консультационной работы, отчёт учредителю.

## 3. Группа «Охват и устойчивость контингента»

### 3.1. KP-02-01. Численность занимающихся на систематической основе

| Параметр | Значение |
|---|---|
| **Группа** | Охват и устойчивость контингента |
| **Единица измерения** | чел. |
| **Периодичность** | ежемесячно, ежеквартально |
| **Ответственный за сбор** | Тренеры, руководители подразделений |
| **Ответственный за расчёт** | Методист / аналитик |

**Обоснование:** ключевой показатель охвата населения — связан с целью «Привлечение жителей БМО к регулярным занятиям ФКиС».

**Формула:**

```
Ч = Σ Ч_i (по группам/секциям/программам)
```

Где `Ч_i` — среднесписочная численность занимающихся в i-й группе за период (по журналам посещаемости).

Дополнительно рассчитывается доля охвата населения:

```
Д_охват = (Ч / Население_БМО) × 100%
```

**Шкала оценки (по доле охвата населения):**

| Уровень | Значение | Интерпретация |
|---|---|---|
| Критический | < 20% | Низкий охват |
| Низкий | 20–34% | Охват ниже среднего |
| Средний | 35–49% | Средний охват |
| Высокий | ≥ 50% | Высокий охват |

**Целевые значения:** ежегодный прирост численности на 3–5%; доля охвата — в соответствии с муниципальным заданием.

**Источники данных:** журналы посещаемости, АИС «Спорт», статистика ЕМИСС, данные переписи населения.

**Управленческие решения:** планирование набора, маркетинг секций, корректировка муниципального задания.

### 3.2. KP-02-02. Коэффициент сохранности контингента

| Параметр | Значение |
|---|---|
| **Группа** | Охват и устойчивость контингента |
| **Единица измерения** | % |
| **Периодичность** | ежегодно |
| **Ответственный за сбор** | Тренеры, методист |
| **Ответственный за расчёт** | Методист / аналитик |

**Обоснование:** отражает устойчивость контингента и качество удержания занимающихся — важнейший качественный аспект эффективности.

**Формула:**

```
К_ск = (N_продолжили / N_на начало года) × 100%
```

Где:
- `N_продолжили` — число занимающихся, продолживших занятия на конец года;
- `N_на начало года` — число занимающихся на начало года.

**Шкала оценки:**

| Уровень | Значение | Интерпретация |
|---|---|---|
| Критический | < 60% | Массовый отток |
| Низкий | 60–74% | Заметный отток |
| Средний | 75–89% | Приемлемая сохранность |
| Высокий | ≥ 90% | Высокая устойчивость |

**Целевые значения:** Год 1 — 80%; Год 2 — 85%; Год 3 — 90%.

**Источники данных:** журналы посещаемости, приказы о зачислении/отчислении, АИС.

**Управленческие решения:** выявление программ с оттоком, опросы причин ухода, корректировка расписания, повышение квалификации тренеров.

### 3.3. KP-02-03. Доля населённых пунктов округа, охваченных проектами

| Параметр | Значение |
|---|---|
| **Группа** | Охват и устойчивость контингента |
| **Единица измерения** | % |
| **Периодичность** | ежегодно |
| **Ответственный за сбор** | Отдел мероприятий |
| **Ответственный за расчёт** | Методист / аналитик |

**Обоснование:** отражает равномерность территориального охвата (проекты «Спорт на селе», «Село — территория долголетия») и доступность услуг — одну из выявленных проблемных зон.

**Формула:**

```
Д_тер = (N_пунктов_охвачено / N_пунктов_всего) × 100%
```

Где:
- `N_пунктов_охвачено` — число населённых пунктов БМО, где проведены мероприятия/работают группы;
- `N_пунктов_всего` — общее число населённых пунктов округа.

**Шкала оценки:**

| Уровень | Значение | Интерпретация |
|---|---|---|
| Критический | < 40% | Большинство пунктов не охвачено |
| Низкий | 40–59% | Частичный охват |
| Средний | 60–79% | Достаточный охват |
| Высокий | ≥ 80% | Практически полный охват |

**Целевые значения:** Год 1 — 60%; Год 2 — 70%; Год 3 — 80%.

**Источники данных:** отчёты по проектам, планы мероприятий, паспорта поселений.

**Управленческие решения:** корректировка географии проектов, распределение выездных бригад, развитие инфраструктуры на селе.

## 4. Группа «Удовлетворённость потребителей»

### 4.1. KP-03-01. Независимая оценка качества условий оказания услуг (НОК)

| Параметр | Значение |
|---|---|
| **Группа** | Удовлетворённость потребителей |
| **Единица измерения** | балл (0–100) |
| **Периодичность** | ежегодно (по результатам НОК) |
| **Ответственный за сбор** | Методист / аналитик (данные ГИС ГМУ) |
| **Ответственный за расчёт** | Методист / аналитик |

**Обоснование:** отражает качество услуг с точки зрения потребителей (родители, занимающиеся, участники мероприятий) через внешнюю независимую оценку, проводимую по единой методике для организаций социальной сферы. Это фактический подтверждённый источник удовлетворённости, размещаемый в ГИС ГМУ.

**Формула:**

Показатель принимается равным **итоговому баллу НОК** (0–100), рассчитываемому оператором НОК по критериям:

```text
НОК = Σ (Критерий_i × Вес_i)
```

Критерии НОК:
- открытость и доступность информации об организации;
- комфортность условий предоставления услуг;
- доступность услуг для инвалидов;
- доброжелательность, вежливость работников;
- удовлетворённость условиями оказания услуг.

Дополнительно: оценка граждан (1–5) и доля опрошенных от числа получателей услуг.

**Фактическое значение (апробация, 2026):** **97,1 балла** — Высокий уровень. Получателей услуг — 189 чел., опрошено 145 (77%). Оценка граждан — 5 из 5.

**Шкала оценки:**

| Уровень | Значение | Интерпретация |
|---|---|---|
| Критический | < 50 | Серьёзные проблемы качества |
| Низкий | 50–69 | Значительные замечания |
| Средний | 70–84 | В целом удовлетворены |
| Высокий | ≥ 85 | Высокая удовлетворённость |

**Целевые значения:** Год 1 — 80; Год 2 — 84; Год 3 — 88.

**Источники данных:** ГИС ГМУ (bus.gov.ru, карточка учреждения), результаты независимой оценки качества; файлы «Оценка», «эффективность.csv».

**Управленческие решения:** корректировка программ, работа с персоналом, улучшение информирования, развитие сервисов записи.

**Источники данных:** журнал обращений, электронная почта, соцсети, портал обратной связи.

### 4.3. KP-03-03. Удовлетворённость информацией на сайте и стендах (подкритерии НОК)

| Параметр | Значение |
|---|---|
| **Группа** | Удовлетворённость потребителей |
| **Единица измерения** | балл (0–100) |
| **Периодичность** | ежегодно (по результатам НОК) |
| **Ответственный за сбор** | Методист / аналитик (данные ГИС ГМУ) |
| **Ответственный за расчёт** | Методист / аналитик |

**Обоснование:** отражает доступность и понятность информации об организации — один из критериев НОК, непосредственно влияющий на итоговый балл удовлетворённости и открытость учреждения.

И_инф = (N_удовл_инф / N_опрошенных) × 100

| Уровень | Значение | Интерпретация |

| Низкий | 50–69 | Значительные замечания |
| Средний | 70–84 | В целом доступна |
| Высокий | ≥ 85 | Высокая доступность информации |

**Целевые значения:** Год 1 — 80; Год 2 — 84; Год 3 — 88.

**Источники данных:** ГИС ГМУ (результаты НОК), файл «Оценка».

**Управленческие решения:** повышение открытости и доступности информации, обновление сайта и стендов, развитие дистанционных каналов взаимодействия.

## 5. Группа «Эффективность использования ресурсов»

### 5.1. KP-04-01. Укомплектованность основного персонала

| Параметр | Значение |
|---|---|
| **Группа** | Эффективность использования ресурсов (кадровые) |
| **Единица измерения** | % |
| **Периодичность** | ежегодно |
| **Ответственный за сбор** | Отдел кадров / бухгалтерия |
| **Ответственный за расчёт** | Методист / аналитик |

**Обоснование:** отражает обеспеченность учреждения основным персоналом (тренеры/педагоги) — критически важный кадровый ресурс для оказания услуг ФКиС.

**Формула:**

```
У_осп = (N_замещено_осн / N_штат_осн) × 100%
```

Где:
- `N_замещено_осн` — число замещённых должностей основного персонала;
- `N_штат_осн` — число штатных должностей основного персонала.

**Фактическое значение (апробация, 2025):** **100%** — 25 замещённых должностей из 25 штатных (основной персонал). Для всего персонала: 31 замещённая должность из 32,8 штатных — **94,5%**.

**Шкала оценки:**

| Уровень | Значение | Интерпретация |
|---|---|---|
| Критический | < 50% | Низкая укомплектованность |
| Низкий | 50–64% | Заметный дефицит кадров |
| Средний | 65–79% | Приемлемый уровень |
| Высокий | ≥ 80% | Высокая укомплектованность |

**Целевые значения:** Год 1 — 90%; Год 2 — 95%; Год 3 — 100% (основной персонал).

**Источники данных:** ГИС ГМУ (bus.gov.ru, карточка учреждения), кадровые документы; файлы «численность1.csv» (2024), «численность2.csv» (2025).

**Управленческие решения:** планирование найма, программа привлечения и закрепления тренеров, повышение квалификации, пересмотр оплаты труда.

### 5.2. KP-04-02. Загрузка инфраструктуры

| Параметр | Значение |
|---|---|
| **Группа** | Эффективность использования ресурсов (инфраструктурные) |
| **Единица измерения** | % |
| **Периодичность** | ежеквартально |
| **Ответственный за сбор** | Администратор, отдел мероприятий |
| **Ответственный за расчёт** | Методист / аналитик |

**Обоснование:** отражает эффективность использования площадей и оборудования.

**Формула:**

```
З_инфр = (Ч_факт_использования / Ч_доступно) × 100%
```

Где:
- `Ч_факт_использования` — часы фактического использования залов/площадок;
- `Ч_доступно` — доступные часы (с учётом режима работы).

**Шкала оценки:**

| Уровень | Значение | Интерпретация |
|---|---|---|
| Критический | < 40% | Недозагрузка инфраструктуры |
| Низкий | 40–54% | Существенный простой |
| Средний | 55–74% | Разумная загрузка |
| Высокий | ≥ 75% | Максимальная загрузка |

**Целевые значения:** Год 1 — 70%; Год 2 — 75%; Год 3 — 80%.

**Источники данных:** расписание, журналы аренды, отчёты администраторов.

**Управленческие решения:** оптимизация расписания, развитие платных услуг, сбалансированная аренда (с учётом юридических коллизий).

### 5.3. KP-04-03. Доля внебюджетных доходов

| Параметр | Значение |
|---|---|
| **Группа** | Эффективность использования ресурсов (финансовые) |
| **Единица измерения** | % |
| **Периодичность** | ежегодно |
| **Ответственный за сбор** | Отдел бухгалтерского учёта |
| **Ответственный за расчёт** | Аналитик / бухгалтерия |

**Обоснование:** отражает финансовую устойчивость и способность привлекать внебюджетные средства (платные услуги, гранты, аренда). Показатель соответствует блоку «А — финансовая автономия» интегральной оценки эффективности учреждения в ГИС ГМУ.

**Формула:**

```
Д_внеб = (Д_внеб / Д_всего) × 100%
```

Где:
- `Д_внеб` — внебюджетные доходы (платные услуги, гранты, аренда);
- `Д_всего` — общий объём доходов (бюджет + внебюджет).

**Фактическое значение (апробация, ГИС ГМУ):** **0%** — доходы от приносящей доход деятельности отсутствуют (оценка финансовой автономии А = 0; финансовая устойчивость У = 0 по данным интегральной оценки эффективности учреждения — 15,78 балла, низкая).

**Шкала оценки:**

| Уровень | Значение | Интерпретация |
|---|---|---|
| Критический | < 5% | Полная зависимость от бюджета |
| Низкий | 5–9% | Слабая диверсификация |
| Средний | 10–19% | Заметная внебюджетная составляющая |
| Высокий | ≥ 20% | Устойчивая модель |

**Целевые значения:** Год 1 — 10%; Год 2 — 15%; Год 3 — 20%.

**Источники данных:** бухгалтерская отчётность, план ФХД, отчёты об исполнении.

**Управленческие решения:** развитие платных услуг, подача грантовых заявок, обоснование дополнительного финансирования учредителем.

## 6. Группа «Организационный эффект»

### 6.1. KP-05-01. Коэффициент текучести кадров

| Параметр | Значение |
|---|---|
| **Группа** | Организационный эффект |
| **Единица измерения** | % |
| **Периодичность** | ежегодно |
| **Ответственный за сбор** | Отдел кадров |
| **Ответственный за расчёт** | Методист / аналитик |

**Обоснование:** отражает стабильность коллектива и качество организационного климата.

**Формула:**

```
К_тек = (N_уволено / N_среднесписочная) × 100%
```

Где:
- `N_уволено` — число уволенных за период (без сокращений);
- `N_среднесписочная` — среднесписочная численность персонала за период.

**Шкала оценки:**

| Уровень | Значение | Интерпретация |
|---|---|---|
| Критический | > 25% | Нестабильный коллектив |
| Низкий | 16–25% | Повышенная текучесть |
| Средний | 8–15% | Приемлемый уровень |
| Высокий | < 8% | Стабильный коллектив |

**Целевые значения:** Год 1 — 15%; Год 2 — 12%; Год 3 — 10%.

**Источники данных:** кадровые документы, приказы, отчёты по кадрам.

**Управленческие решения:** программа удержания персонала, совершенствование мотивации, анализ причин увольнений.

### 6.2. KP-05-02. Индекс вовлечённости персонала

| Параметр | Значение |
|---|---|
| **Группа** | Организационный эффект |
| **Единица измерения** | балл (0–100) |
| **Периодичность** | ежегодно |
| **Ответственный за сбор** | HR / методист |
| **Ответственный за расчёт** | Методист / аналитик |

**Обоснование:** отражает мотивацию и лояльность сотрудников, влияет на качество услуг и достижение KPI.

**Формула:**

```
И_вовл = (Σ Оценок сотрудников / N_сотрудников) × 100
```

Оценка по опроснику вовлечённости (удовлетворённость работой, гордость за организацию, готовность рекомендовать, понимание целей).

**Шкала оценки:**

| Уровень | Значение | Интерпретация |
|---|---|---|
| Критический | < 50 | Демотивированный коллектив |
| Низкий | 50–64 | Слабая вовлечённость |
| Средний | 65–79 | Умеренная вовлечённость |
| Высокий | ≥ 80 | Высокая вовлечённость |

**Целевые значения:** Год 1 — 70; Год 2 — 75; Год 3 — 80.

**Источники данных:** анонимные опросы сотрудников, собеседования, наблюдение руководителей.

**Управленческие решения:** система мотивации и премирования, мероприятия по климату, развитие персонала, привязка премий к KPI.

## 7. Расчёт интегрального индекса эффективности

### 7.1. Алгоритм

1. Каждый показатель переводится в балльную оценку (0–100) по своей шкале (линейная интерполяция между границами уровней либо экспертная оценка).
2. Внутри группы показателей вычисляется среднее арифметическое (либо взвешенное по важности) — оценка группы.
3. Интегральный индекс:

```
И = Σ (Оценка_группы_i × Вес_i)
```

Где `Вес_i` — вес i-й группы (см. раздел 1).

### 7.2. Интерпретация интегрального индекса

| Уровень | Значение | Рекомендуемые действия |
|---|---|---|
| Критический | < 40 | Антикризисный план, пересмотр задания, доп. финансирование |
| Низкий | 40–59 | Точечные корректировки, перераспределение ресурсов |
| Средний | 60–79 | Плановое развитие, приоритизация слабых направлений |
| Высокий | 80–100 | Масштабирование практик, презентация результатов |
